# ORM Service Frontend Prototype

This repository contains a Flutter UI prototype. The entry point opens a sample interaction screen. A separate login-screen mockup lives in the same file. [Flutter entry point](frontend/lib/main.dart)

## Local setup

The app declares Dart `>=2.19.2 <3.0.0`. Use a Flutter SDK with a Dart version in that range. [Flutter package configuration](frontend/pubspec.yaml)

~~~sh
cd frontend
flutter pub get
flutter run
~~~
